Check it yourself (test of connections from outside)

This page only looks at the connection from the app (Edge Function) to the database. Connections from outside, such as psql, are separate, so check them with the script below (it uses a deliberately wrong password).

export PGHOST="aws-0-<region>.pooler.supabase.com"
export PGUSER="postgres.<PROJECT_REF>"
./scripts/check-ssl.sh
# If SSL is enforced: sslmode=disable is refused with (ESSLREQUIRED)
